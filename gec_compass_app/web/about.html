About GECT Compass

The ultimate indoor and outdoor campus navigation system for Government Engineering College (GEC) Thrissur. Designed to help students, faculty, staff, and visitors navigate every department, lab, classroom, and amenity seamlessly.

Our Mission

Navigating a sprawling 120-acre engineering campus like GEC Thrissur can be challenging for freshers, event attendees, and visitors. GECT Compass was built to solve campus navigation through accurate Dijkstra road-network routing, real-time GPS tracking, live compass direction, and offline capability.

Created as a non-profit community project by passionate students and alumni (Gectians), GECT Compass delivers a state-of-the-art digital mapping experience dedicated to serving the entire GEC TCR family.

App Features

🗺️

High-Definition Campus Map

Detailed satellite and labeled vector map covering all main blocks, department workshops, auditoriums, hostels, and amenities.

🚶

Turn-by-Turn Road Routing

Powered by Dijkstra shortest-path algorithms mapped precisely along internal campus walkways and roads.

📍

Real-Time GPS & Compass

Live blue-dot location indicator with hardware compass heading detection to keep you oriented on campus grounds.

⚡

Offline Routing Capability

Engineered with offline caching so navigation functions seamlessly even in low connectivity zones.

🏢

Complete Room Directory

Quick search directory for CSE, ECE, EEE, ME, CE, CHE, PE, MCA departments, CCF, central library, and labs.

☁️

Cloud Place Sync

Real-time serverless synchronization enabling custom place updates across mobile and web platforms.
